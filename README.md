# Devamsızlık Takip · Öğretmen Uygulaması

Öğretmenlerin kendi şubelerindeki devamsız öğrenciler için telefon görüşmesi, okula davet / veli görüşmesi ve ev ziyareti kayıtlarını telefondan girdiği web uygulaması.

- Öğretmen okulun verdiği **ortak şifreyle** girer ve **şubesini seçer**; yalnızca o şubenin takipteki öğrencilerini, yapılacakları ve son e-Okul mektuplarındaki **devamsızlık artışlarını** görür.
- Kayıtlar okulun Google E-Tablo tabanlı Devamsızlık Takip Sistemi'ne, öğretmen formuyla aynı şekilde işlenir. İmzalı tutanağın fotoğrafı da eklenebilir.
- Bu depoda **öğrenci bilgisi yoktur**. Veriler yalnızca okulun Google hesabındaki tabloda durur; uygulama onları şifreyle, anlık olarak okur ve telefona kaydetmez.

## Telefona kurma

1. Okulun verdiği bağlantıyı telefonda açın.
2. **Android (Chrome):** sağ üstteki ⋮ menüsü → **Ana ekrana ekle** / **Uygulamayı yükle**.
   **iPhone (Safari):** alttaki paylaş düğmesi → **Ana Ekrana Ekle**.
3. Ana ekrandaki **Devamsızlık** simgesiyle açın, şifreyi yazıp şubenizi seçin.

Giriş 30 gün hatırlanır. Şube değiştirmek için sağ üstteki çıkış düğmesine basıp yeniden girin.
